画面の見た目を確かめるための試作です。データは見本で、保存などは動きません。詳しくは docs/screen-design.md（画面設計書）を参照。

ID画面

確かめ方

  • スマホの見た目：ブラウザで F12 → 端末のアイコン（Ctrl＋Shift＋M）で幅を 320px などに変える
  • ダークモード：Windows の設定 → 個人用設定 → 色 →「ダーク」
  • 通知：詳細画面の「作った」→「記録する」、登録画面の「保存する」など
